# Кампус Зил — редизайн сайта

Статический одностраничный сайт образовательного центра «Кампус Зил» (campuszil.com).
Без сборки и зависимостей: HTML + CSS + JS.

## Структура

```
index.html        — лендинг, все секции
about.html        — страница «О центре»: кто мы, сравнение со школой, направления, клуб
news.html         — лента новостей с фильтром по темам
licence.html      — страница «Лицензия» (реквизиты + выписка из реестра)
vacancies.html    — страница «Вакансии»
css/style.css     — стили (дизайн‑система «Инженерная тетрадь»)
js/main.js        — данные курсов и расписания, фильтры, карусель, меню (лендинг)
js/page.js        — меню и год в подвале для внутренних страниц
js/news-data.js   — записи новостей (данные)
js/news.js        — рендер ленты и блока «Новости» на главной
assets/img/       — фотографии: с текущего сайта и сгенерированные (см. ниже)
assets/icons/     — SVG‑иконки направлений, сгенерированы через Higgsfield (Recraft)
assets/docs/      — выписка из реестра лицензий (PDF)
assets/favicon.svg
PRODUCT.md        — факты о продукте и аудитории
DESIGN.md         — визуальные правила: цвета, шрифты, компоненты
```

## Запуск локально

```
python3 -m http.server 8765
# открыть http://localhost:8765/
```

Шрифты Unbounded и Golos Text подгружаются с Google Fonts. Если нужен полностью
автономный вариант, скачайте их и подключите через `@font-face`.

## Где править контент

Все курсы, цены, возраст и слоты расписания лежат в `js/main.js`:

- `COURSES` — карточки направлений. Поля: `title`, `cat` (tech / study / lang / games),
  `minAge`, `maxAge`, `price`, `per`, `format`, `desc`, `days`, `photo`,
  `board: true` + `boardLabel` — показывать стикер в первом экране.
- `SLOTS` — постоянные группы недели, добавляются через `add(день, начало, конец, название, категория, пометка)`.
  День: 0 = понедельник. Время задаётся `t(часы, минуты)`.

Преподаватели, контакты и тексты секций — прямо в `index.html`.

Новости лежат в `js/news-data.js`, массив `NEWS`. Новая запись — объект сверху
массива: `id`, `date` (ГГГГ-ММ-ДД), `tag` из `NEWS_TAGS`, `title`, `body`
(абзацы строками, списки как `{list:[...]}`), по желанию `image`/`images`,
`video` и `link`. Главная показывает три последние записи автоматически.

## Деплой

Любой статический хостинг: Vercel, Netlify, GitHub Pages, папка на текущем хостинге.
Заявка на пробный урок ведёт на виджет Яндекс Бизнеса (как на старом сайте).

## Проверка вёрстки

`docs/overflow-check.mjs` прогоняет страницу по 18 ширинам экрана (320–1920 px)
и печатает элементы, которые вылезают за край окна, за границы hero или своей
карточки. Нужен пакет playwright с браузером Chromium:

```
npm i -D playwright && npx playwright install chromium
node docs/overflow-check.mjs
```

## Сгенерированные изображения

Иконки направлений и часть фотографий сделаны через Higgsfield CLI, скрипты
и промпты лежат в `docs/generation/`. Настоящие фото с сайта центра:
`robotics-*.jpg`, `chess-*.jpg`, `english.jpg`, `calligraphy.jpg`, `otto.jpg`, `teacher-vinogradov.jpg`, `about-*.jpg`.
Сгенерированные: `school`, `math`, `3d`, `arduino`, `tv`, `early`, `engineer`,
`reading`, `games-dev`, `eng-start`. Галерея «Как проходят занятия» использует
только настоящие снимки.

Новая иконка: добавить строку `id|описание` в `docs/generation/icons.txt`,
запустить `docs/generation/gen-icons.sh`, затем `python3 docs/generation/clean-svg.py`.
